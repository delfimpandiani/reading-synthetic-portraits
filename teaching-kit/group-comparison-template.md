## Comparison discussion

1. Which features emerged across groups despite different theoretical orientations?
2. Which features emerged only in one theoretical orientation?
3. Which concepts helped interpretation without yielding stable visual features?
4. Which codebook decisions changed after pilot coding?
5. How did corpus context or synthetic situation shape each group’s codebook?
6. Which categories would travel well to another corpus, and which require substantial adaptation?
