
# Exercise: Shared codebook workshop

## Setup

All students receive the same corpus and theoretical orientation. Students begin with individual observation, then negotiate one group codebook.

## Task

1. Inspect 15–20 images individually.
2. Create individual seed-feature lists.
3. Compare lists in groups.
4. Merge, split, rename, retain, and remove candidate features.
5. Build a 10–20-feature codebook.
6. Pilot code a fresh sample.
7. Document revisions in Worksheet 5.
8. Produce a short prevalence table and interpretation memo.

## Learning question

How does a shared codebook emerge from disagreement, visual evidence, theoretical orientation, and practical needs for clarity?
