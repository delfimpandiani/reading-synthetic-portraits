
# Exercise: Same theory, different synthetic situations

## Setup

All groups use the same theoretical orientation. Each group studies a different synthetic-image situation.

Possible situations:

- a commercial text-to-image generator;
- a public installation;
- a platform profile-image generator;
- an archival visualisation project;
- an AI-assisted game-avatar system;
- a fixed-template public-service image tool.

## Task

1. Use the same theoretical concepts across all groups.
2. Complete a synthetic-situation map for each corpus.
3. Generate seed features and a small codebook.
4. Compare the codebooks across groups.
5. Identify which features travel, which change, and which fail to apply.

## Learning question

How do interfaces, prompts, categories, participation, and technical conditions shape the features that become relevant in a theoretical analysis?
