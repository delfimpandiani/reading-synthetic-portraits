
# Exercise: Same corpus, different theoretical orientations

## Setup

All groups analyse the same instructor-provided sample of synthetic images. Each group receives a different theoretical orientation.

Suggested orientations:

- feminist theory: gender display, aesthetic labour, objectification;
- postcolonial theory: othering, colonial gaze, racialised perception;
- affect theory: atmosphere, bodily orientation, vulnerability, intensity;
- queer theory: normativity, gender legibility, desire, respectability;
- disability theory: embodiment, normalcy, access, visibility;
- critical race theory: racialisation, stereotype, surveillance, representation.

## Task

1. Complete Worksheets 1 and 2.
2. Inspect the same 15–20 images individually using Worksheet 3.
3. Build a group codebook of 10–15 provisional features.
4. Pilot code a further 10–15 images.
5. Revise the codebook.
6. Present three features, one difficult case, and one contextual limit.

## Learning question

How does theoretical orientation shape what becomes visible, codeable, and interpretable in the same synthetic-image corpus?
