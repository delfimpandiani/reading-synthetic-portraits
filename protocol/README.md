# Theory-Informed Feature Coding for Synthetic Images

This folder provides a reusable protocol for analysing representational power in synthetic images. It supports researchers, students, and research teams who want to use feminist, postcolonial, affect, queer, decolonial, disability, critical race, or other critical theory as a sensitising orientation for systematic visual analysis.

The protocol supports a process in which researchers:

1. document the synthetic situation that produced a corpus;
2. establish a theoretical orientation;
3. inspect images for recurring visual patterns;
4. develop provisional, observable features;
5. construct a codebook collaboratively;
6. pilot and revise the codebook;
7. produce descriptive analysis;
8. interpret findings in relation to theory and the full image-production arrangement.

## What this protocol provides

- a question-based workflow;
- a synthetic-situation worksheet;
- guidance for moving from theory to observable features;
- a reusable codebook template;
- annotation guidance;
- guidance on interpretation, limits, and responsible claims.

## What this protocol does not provide

This protocol does not provide a universal list of harmful visual features or a general measure of model bias. It provides a documented process through which feature categories can be developed, tested, evaluated, revised, and contested in relation to a particular corpus and synthetic situation.

## Start here

1. Complete `synthetic-situation-worksheet.md`.
2. Read `theory-to-codebook-guide.md`.
3. Follow the eight stages in `protocol.md`.
4. Copy `codebook-template.csv` and create a project-specific codebook.
5. Use `annotation-guide.md` during pilot coding.
6. Read `interpretation-and-limits.md` before reporting results.
