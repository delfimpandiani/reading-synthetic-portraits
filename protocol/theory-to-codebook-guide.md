# From Theory to Codebook

## The core methodological move

Critical theory can guide visual analysis without becoming a fixed checklist. Feminist, postcolonial, affect, queer, decolonial, disability, critical race, and related traditions provide concepts that sensitise researchers to questions of representational power. They may direct attention toward othering, racialised embodiment, gender display, objectification, visual hierarchy, affect, legibility, normativity, surveillance, or visibility.

The images still determine which features can be described, distinguished, and consistently coded.

## Three levels to keep distinct

| Level | Function | Example |
|---|---|---|
| Theoretical orientation | Guides attention toward a problem | Feminine touch, colonial gaze, body schema |
| Visual observation | Describes what is visibly present | Hand rests against cheek; subject looks away |
| Feature and interpretation | Defines a code, then explains its possible significance | Hand-to-face pose; possible gendered aesthetic display |

A concept such as objectification should not become a direct code unless it can be operationalised through visible features. It may guide researchers to inspect framing, bodily exposure, camera angle, gaze, gesture, beautification, or composition.

## Recommended workflow

### 1. Begin with broad questions

Ask what kinds of representational power the theoretical orientation makes relevant. Avoid beginning with a final list of expected image features.

### 2. Inspect images before fixing categories

Record descriptions such as:

- “The body is cropped at the lower torso.”
- “The head is tilted and the hand touches the cheek.”
- “Eyes appear downward.”
- “The background is dark and the body is seated.”
- “Skin texture is strongly smoothed.”

These descriptions can later become candidate features.

### 3. Develop seed features

Move from description to a provisional, observable name:

| Description | Candidate feature |
|---|---|
| Eyes directed away from viewer | Averted gaze |
| Palm or fingers touch face | Hand-to-face pose |
| Body visibly contracts inward | Minimising body language |
| Strong smoothing and cosmetic enhancement | Make-up / beautification |

### 4. Require observable evidence

A feature should have:

- a visible basis;
- a definition that distinguishes it from nearby features;
- inclusion and exclusion guidance;
- examples and borderline cases;
- enough clarity for other researchers to attempt application.

### 5. Treat disagreement as information

Disagreement can reveal:

- an imprecise definition;
- overlapping categories;
- an image that is genuinely ambiguous;
- a theoretical concept that remains interpretive rather than codeable;
- differences in researchers’ visual or cultural assumptions.

### 6. Separate coding from interpretation

Code the visible feature first. Interpret its possible representational meaning after coding, using theory and the synthetic situation.

For example:

> **Code:** Averted gaze is visibly present.
>
> **Interpretation:** In combination with posture, framing, and the corpus context, averted gaze may contribute to a visual organisation of reduced reciprocal recognition.

## Strong and weak features

A **strong feature** appears clear, stable, and visually well-defined. A **weak feature** appears distorted, unstable, partial, or peculiar. Weak features can be valuable because they may direct attention to uneven cultural legibility or failures of visual representation. They require careful definition and cautious interpretation.

Do not infer a precise technical cause from a weak feature alone. Use it as a prompt for further contextual and comparative analysis.

## A practical test

Before retaining a feature, ask:

1. Can we point to it in an image?
2. Can we describe it without assuming intent or identity?
3. Can we distinguish it from an adjacent feature?
4. Can another researcher apply it using our written guidance?
5. Does it remain meaningful in relation to the theoretical orientation?
6. What would make us revise or remove it?
